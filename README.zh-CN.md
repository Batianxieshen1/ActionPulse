## 它想解决什么

大多数待办应用本质上是**存储**。它们帮你把事情记下来，然后把最难的部分原样丢回给你：

> 你打开应用，看到 27 条待办，觉得累，然后关掉。

「知道该做什么」和「真的开始做」之间的那道缝，才是任务真正死掉的地方。ActionPulse 是围着那道缝设计的，不是围着存储设计的。

由此推出三条原则：

1. **清单必须告诉你下一个做什么，而且你得看得懂为什么。** 拒绝黑箱排序。
2. **开始的动作必须比决定更省力。** 聚焦模式、2 分钟破冰、加权盲盒，替你把这步做掉。
3. **清单绝不能变成负罪感来源。** 习惯不滚存逾期，陈旧任务休眠而不是在你眼前腐烂。

## 功能

### 可解释的紧迫度，不是黑箱

每个任务都有一个你能推演的分数；展开卡片详情，四个分项各贡献了多少一目了然：

```
score = clamp( round( (35·I + 40·D + 15·Q + 10·A) / 108 × 100 ), 0, 100 )

  I  重要度        high / medium / low
  D  截止压力      已超期 1.2 · 今天 1.0 · 明天 0.7 · 3 天内 0.4 · 更远或无截止 0.1
  Q  速赢加成      ≤15 分钟 1.0 · ≤60 分钟 0.5 · 更久或未估时 0.2
  A  搁置补偿      min(创建天数 / 7, 1)   ← 防止小事被无限期搁置
```

权重有单测把关：断言「高优 + 已超期」必须排在「低优 + 无期限」之前，所以公式不会悄悄漂移。

### 只做一件事的聚焦模式

全屏台面，只显示一个任务，其他全部消失。点「不是这个」换掉它，点「完成了」进入下一件。

如果这件事看起来太大，可以在原地拆成 3~5 个微步骤——默认走离线动词模板，配置了 LLM 就用你自己的。

### 🎲 盲盒决策

当清单最上面几件看起来一样可怕时，掷骰子。它从**前三名**里抽一个，直接把你推进聚焦模式。

抽取是**按紧迫度加权**的，不是均匀随机——均匀随机会把第一名的胜率压到 1/3，等于让整套排序白算。你要的是用来打破纠结的随机性，不是把算法扔掉。

### ⚡ 2 分钟破冰

任何任务最难的永远是头两分钟。打开 120 秒倒计时，文案是「只要做两分钟，之后你可以停」。

响铃之后你可以停，也可以一键**续杯**成完整的 25 分钟番茄钟，顺着惯性继续。中途退出的话，已经跑满的整分钟也会被记进专注时长，不白费。

### ⚡ 每日习惯

面板顶部一行紧凑药丸，放你每天都要做的事。点一下完成，再点一下取消。

- **永远不会超期。** 昨天没打勾，不会变成今天的债。跨天归零是**派生**的（按当前日期算），所以不存在会跑偏的重置定时器。
- **同步不可能冲突。** 完成记录是只增集合，两台设备合并就是取并集——满足交换律、结合律、幂等。手机和电脑可以各自离线打勾，最后一定收敛到同一份。
- **全部完成不会立刻把这一行收走。** 等 1.5 秒再收拢，好让「打勾成功」这件事被看见。

### 🧊 僵尸任务休眠

**14 天**没动过、且没有截止日期的任务，会自动移到底部折叠起来的「冷却休眠区」，不再争夺注意力。但什么都不会被删除。

每条休眠任务给三个出口：**给它定个日子**、**唤醒**、**删掉**。只唤醒其实是个陷阱——你不管它，14 天后它又会休眠。界面上写了这句话。

**有截止日期的任务永不休眠**：那是对别人的承诺，藏起来比摆在眼前更糟。

### 🏆 今日战报

今天该做的全部清空时，你会看到一条提示，而**不是**弹一个挡住屏幕的模态框。任何时候点能量槽都能打开完整战报：完成数、专注时长、连击峰值、习惯达成率、连续天数，一键复制成 Markdown。战报还带**近 7 天完成分布**——「速赢因子会不会一直喂你小任务」这件事，从此有数据可查。

### ⌨️ 自然语言极速输入

把元数据直接写进标题里，不点下拉框，不碰鼠标：

```
写季度汇报 !high 明天 ~30m
```

| 语法 | 含义 |
| :--- | :--- |
| `!high` `!med` `!low`（也接受 `!h` `!m` `!l`） | 重要度 |
| `今天` `明天` `后天` `周一`…`周日` | 截止日期 |
| `~5m` `~30m` `~1h` `~20分钟` | 预估耗时——**开放区间**，写 `~45m` 一样有效 |

解析结果会**实时显示成胶囊**：看不见的解析器就是不可信的解析器。文本标记优先于下拉框，而且不会污染下拉框记住的值。

> **`周一` 一律解析为「下一个周一」，包含今天，永远不会产生过去的日期。**
> 否则你在周三写「周一」，任务会立刻变成「已超期」并冲上榜首——你用自然语言省了事，却被系统惩罚一次。

### 深色 / 浅色，无障碍标准由测试把关

两套完整配色，令牌一一对应，默认跟随系统。浅色**不是**把深色反过来——深色主色（电光柠檬）在白底上的对比度只有 **1.24:1**，浅色只能是重新设计的一套。

`tests/theme.test.ts` 会解析 CSS、模拟 shell → 面板 → 卡片的叠加，断言两套主题下每个文字色在所有底色上都 **≥ 4.5:1**。这个测试写出来的那一刻，立刻照出**原本的深色主题**有两个令牌不达标，两个都修了。

切换主题不会闪屏：`<head>` 里有一段内联脚本在首次绘制前就设好 `data-theme`。验证方式是**把所有 JS 全部拦掉**，确认 React 还没挂载时属性已经是正确的。

## 快速开始

只需要 **Node 20+**。没有数据库、没有 Docker、不需要注册账号。

> 不想装 Node？[在线体验](https://batianxieshen1.github.io/ActionPulse/)（纯客户端演示）——数据只存在你自己的浏览器里；没有多端同步和 AI 语义拆解，其余功能完整。

```bash
git clone https://github.com/Batianxieshen1/ActionPulse.git
cd ActionPulse
npm install
npm start
```

终端会打印带配对 token 的地址。桌面打开它；手机连同一个 Wi-Fi 也能打开，打开即自动完成配对：

```
▶  ActionPulse 脉冲行动 · 本地服务
  ├─ 桌面:   http://localhost:5273/?token=<你的token>
  ├─ 手机:   http://192.168.1.42:5273/?token=<你的token>   (需同一 Wi-Fi)
  └─ 数据:   ./data/state.json
```

### 命令

| 命令 | 作用 |
| :--- | :--- |
| `npm start` | 构建 + 在 5273 端口启动完整服务 |
| `npm run dev` | Vite 热更新（5273）+ API（5274），一条命令 |
| `npm test` | 305 个单元测试 |
| `npm run build` | 类型检查 + 脚本语法守卫 + Vite 构建 |

## 多端同步

同步是**你自己局域网内的点对点**。没有云端，没有账号，没有不属于你的服务器。

```
   手机  ──┐
           ├──►  跑在你自己机器上的 node:http 服务  ──►  ./data/state.json
   电脑  ──┘          （SSE 推送 + 乐观锁）
```

**冲突模型。** 每个任务按 `updatedAt` 整条「后写胜出」——两台设备几乎同时改同一条任务的不同字段时，较新的整条胜出，这是刻意保持的简单；习惯的完成记录按只增集合逐字段合并，天然无冲突。删除会留下墓碑，所以一台设备删掉的任务不会被另一台的旧数据复活。写入时会带上它所基于的版本号——如果已过期，服务端返回 `409` 和当前状态，客户端合并后重试（最多 3 次）。因为合并满足交换律与幂等，重试会收敛而不是产生重复。

**设置刻意不同步。** 手机静音不该把你的电脑也静音。主题、音量、番茄钟时长都留在各自设备上。

**离线是常态。** 客户端是本地优先的：没有服务端、没有网络、没有 Wi-Fi 都能照常用，下次连上时自动对齐。

### 想在外面也能同步？

局域网方案只覆盖同一个 Wi-Fi。想随时随地访问，把两台设备接进一个私有 mesh VPN（例如 Tailscale）是最小改动——Phone 随后从任何网络都能连到同一个服务，而且顺带拿到 HTTPS，手机端的离线缓存、原生剪贴板、真正的 PWA 会一起可用。

完整对比、云主机方案、以及**为什么不要用路由器端口转发**，见 [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)。

## 架构

```
src/domain/       纯函数，没有 React，没有 I/O   ← 真正的产品逻辑
  urgency.ts        紧迫度算分
  merge.ts          LWW + 墓碑 + 只增集合
  habits.ts         每日习惯
  nlp.ts            自然语言解析
  hibernation.ts    僵尸任务老化
  pick.ts           加权盲盒
  debrief.ts        今日战报
src/store/        reducer + 选择器（唯一数据源）
src/sync/         客户端、SSE、乐观锁
src/ui/           展示组件
server/           零依赖 node:http 后端（只 import node: 内置模块）
```

领域层刻意不依赖 React 也不做 I/O，所以真正难的部分——合并代数、日期边界、解析——都是普通函数配普通测试。

服务端**只** import `node:` 内置模块。这是约束不是巧合：意味着你可以把 `server/` 整个拷到任何装了 Node 的机器上直接跑，不需要 `npm install`，也不会有 lockfile 漂移。

### 技术栈

React 19 · TypeScript · Vite 8 · Tailwind CSS 4 · lucide-react · canvas-confetti · Web Audio 合成音效（不含音频文件）· `node:http` 后端。

### 配置 AI 语义拆解（可选）

不配置也能用——默认走离线动词模板。要接自己的模型，在设置界面填，或者写进 `.env`：

```bash
# 任何 OpenAI 兼容端点都行：OpenAI / DeepSeek / Moonshot / Gemini 兼容层 / 本地 Ollama
AP_LLM_BASE_URL=https://api.openai.com/v1
AP_LLM_API_KEY=sk-...
AP_LLM_MODEL=gpt-4o-mini
# PORT=5273
```

API Key 只存在服务端，界面上只会回显掩码后的形式。

## 测试

```
tests/            305 个单元测试，19 个文件（vitest）
```

覆盖的都是真正容易写错的地方：

- **合并代数**：交换律、幂等，以及「较新的标量字段不能抹掉另一侧的打勾历史」这种最容易搞错的组合。
- **日期边界**：跨年时周几向前解析、习惯跨天归零、恰好 14 天的休眠判定。
- **解析器边角**：标记紧贴中文不打空格、标题里本来就有的 `!` 和 `~`、剥完只剩标记时的兜底。
- **主题对比度**：按真实底色叠加计算 WCAG 比值，外加一条防止颜色字面量重新混进组件的守卫。
- **Service Worker 真的能被解析**：`public/` 下每个文件都会过一遍真正的 JS 解析器。因为打包器不碰这个目录，曾经有一个语法错误让 183 个测试全绿、而 Worker 静默注册失败。

## 常见问题

<details>
<summary><b>为什么不用 Todoist / Things / 滴答清单？</b></summary>

它们作为待办应用都比这个成熟。ActionPulse 不打算赢那个比较——它瞄准的是更窄的问题：**开始做**。如果你已经清楚要做什么、只是没在做，再长的功能列表也帮不上忙。
</details>

<details>
<summary><b>会加标签 / 项目分组 / 循环任务吗？</b></summary>

大概率不会。ActionPulse 的差异化在「开始做」，不在「管理」——管理型功能每加一个，定位就淡一分。循环需求已经以「每日习惯」的形态存在（而且永不产生逾期债务）；其余的，上面提到的专业工具做得更好。
</details>

<details>
<summary><b>我的数据会被上传吗？</b></summary>

不会。数据存在浏览器的 localStorage 和你运行服务的那台机器的 `./data/state.json` 里。整个应用唯一的对外请求是 LLM 接口，而且只有你主动配置了才会有——默认关闭，走离线模板。
</details>

<details>
<summary><b>可以完全不用服务端吗？</b></summary>

可以。`npm start` 是完整体验，但客户端是本地优先的：构建产物放在任何地方单独打开都能用，只是没有多端同步。
</details>

<details>
<summary><b>为什么手机上没有离线缓存？</b></summary>

因为 `http://192.168.x.x` 不是安全上下文，浏览器拒绝注册 Service Worker。用 HTTPS 提供（例如通过 mesh VPN）就能解决。桌面端跑在 `localhost` 上，属于安全上下文，所以那边缓存是正常的。
</details>

<details>
<summary><b>手机连不上电脑怎么办？</b></summary>

先确认手机连的是**同一个 Wi-Fi**。如果还是不通，最常见的原因是路由器开了 **AP 隔离**，或者像**校园网 / 公共 Wi-Fi** 那样禁止客户端之间互访。绕过的办法是让两台设备走一条私有链路：手机开 **USB 网络共享**（推荐，电脑还能继续上网），或者手机开热点让电脑连。详见 [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)。
</details>
